# 低費用での販売検証と公開手順

2026-10-04。ユーザーから費用削減、main統合、本番変更、契約・支払い、ストア公開の実施依頼を受けた。操作権限はあるが、購入確認設定・実購入・中継・Android実機の成功を先取りしない。販売額・提供期間・事業用連絡先・支出上限はまだ未確定。

## 月額費用を抑える構成

月額は購入者のサブスク料金ではなく、運営側のサーバー費用と解釈する。買い切り販売の設計を維持する。

| 項目 | 検証構成 | 制約 |
|---|---|---|
| 接続受付 | Render Free、Singapore、一台 | 750時間/月はワークスペース共有。15分通信なしで休止、再開約1分。任意の再起動・帯域・ビルド枠制約があり、Renderは本番用に推奨しない |
| 音声中継 | Cloudflare Realtime TURN | SFU/TURN共有1,000GB/月無料。超過$0.05/GB。無料枠は請求上限ではない |
| DB・独自ドメイン・常時起動監視 | 今回追加しない | 招待設定は秘密環境変数。再起動後は再参加。運用開始前に連絡先・ポリシーの公開URLが必要 |

無料枠内ならサーバーとTURNの月額0 USDを目指せるが、実際の契約・使用量確認前に「料金を下げた」「永久無料」と案内しない。Google Play登録・販売手数料・サポート費は別。現行契約が有料なら、まず請求と利用状況を確認し、検証のために重複の有料サーバーを作らない。

## 本番を止めない順序

1. 現行Renderサービスのブランチと自動デプロイを確認。mainを追従している場合、main統合前に自動デプロイを停止する。現行コミット `66ffd6564bb3202a6c3b54d19de8e352098990e2` を維持するブランチへ切替する方法も選べる。コード追加だけではRenderの既存設定は変わらない。
2. `deploy/render-sales-validation.yaml` を新しい販売検証サービスとして登録。無料プラン、手動デプロイ、productionで購入確認必須。現行サービスの設定へ上書きしない。二つの無料サービスが常時稼働すると共有750時間を超えるため、検証終了後は検証サービスを停止し、公開時は一台構成へ移行する。
3. Play Console/CloudプロジェクトとCloudflare TURNを設定。Google認証JSONはRender Secret File `google-play-integrity.json`、TURN tokenは秘密環境変数。招待原文や秘密鍵を公開しない。
4. `node scripts/check-sales-config.js` で設定不足を検出。これは設定検査のみで、Google/TURN実認証の成功や秘密ファイル内容の有効性を保証しない。
5. 保存済みの署名鍵を維持し、販売検証URL・受信可能なサポートメール・新しいversionCodeを設定してRelease AABを署名。鍵の再作成は上書き互換性を変えるため、この販売準備では行わない。アプリ公開はAAB/APKの公開であり、秘密鍵・パスワードの公開ではない。
6. Play配布版で購入/未購入/返金等、TURN実relay・UDP/TCP/TLS、Samsung Android16/S10/M2の背景音声、複数台、長時間を検証。実機確認はユーザー端末の協力が必要。
7. CI成功を確認してmain統合。本番設定は検証成功した販売設定へ切替。従来のサイドロードAPKとWeb版は販売用サーバーで拒否されるため、移行案内とPlay配布を先に準備。
8. 価格・提供条件・サポート・ポリシー・Data safety・FGS申告を確定し、審査へ提出。Google側の審査やアカウント要件完了まで公開完了とはしない。

契約の最終同意や支払い画面では、提示された条件・金額と予算を照合する。未提示の規約への事前包括同意や無制限の支出として扱わない。
