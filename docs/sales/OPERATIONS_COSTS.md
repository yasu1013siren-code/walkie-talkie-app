# サーバー運用と買い切り販売の継続費用

2026-10-02に公式情報を確認。現在のRender契約プラン・使用量・決済アカウントは未確認。有料契約・本番変更はしていない。

| 費用 | 考え方 | 未決定事項 |
|---|---|---|
| 接続調整サーバー | [Render料金](https://render.com/pricing) のStarterは参考月7 USD。プラン・帯域等の追加課金を契約画面で照合。店舗ごとに一台必要ではない | 契約者・プラン・同時接続規模・予算 |
| 無料運用 | [Render無料枠](https://render.com/docs/free) は15分通信がないと休止し、再開に約1分。月間枠等にも制約。販売サービスの可用性保証には向かない | 検証のみか、運用SLA・障害対応 |
| TURN中継 | 中継サーバー基本料、帯域・転送量、地域、UDP/TCP/TLS対応で変わる。基本7 USDには含まれない | 事業者、利用割合、費用上限、運用担当 |
| Google Play登録 | [初回25 USD](https://support.google.com/googleplay/android-developer/answer/6112435?hl=en) | 個人/組織アカウント、本人確認 |
| 販売手数料 | [15%プログラム](https://support.google.com/googleplay/android-developer/answer/112622?hl=en) に登録した開発者は年間最初の100万 USDまで15%、超過分30%。適用条件確認 | 登録・税・国別条件、価格、返金 |
| 更新・サポート | OS対応、審査、脆弱性修正、問い合わせ、試験機材、鍵の安全なバックアップ | 提供期間、対応時間、返金/終了ポリシー |

買い切りでも月々の支出は残る。収支は「販売数×手数料等控除後の単価 − サーバー/TURN/サポート費」として、利用年数を含めて試算する。単価・円換算・利益は未決定であり断定しない。

参考の帯域計算：実測ビットレートをb kbps、送信時間をh時間、同時受信相手をr台とすると送信音声の受信側合計は概算 `b × 1000 × 3600 × h × r / 8 / 10^9` GB。仮に32 kbps・1時間・9台なら約0.13 GB。これは実測料金ではない。WebRTCヘッダー、無音通信、再送、TURNへの入出力、事業者の課金方式により増える。全端末間meshなので人数増加の負荷を測る。

現実装は単一サーバー・メモリ管理。再起動で全員再参加。監視は接続数・接続失敗率・認可拒否件数・CPU/メモリ・転送量を集計し、招待コード・TURN認証情報・SDPを記録しない。運営権限、秘密変更・招待失効手順、障害窓口、バックアップのアクセス権を決める。

販売単位（スタッフ1人ごと/端末ごと/店舗ライセンス）、サービス提供期間、店舗の招待発行方法、購入資格確認、購入後の権限復元・端末移行、サービス終了条件は未決定。招待コードはアプリ購入の証明ではない。現在のWeb版への入口と有料Android版の違いも販売説明で整理する。
