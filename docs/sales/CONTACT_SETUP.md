# 問い合わせ先

確認日：2026-10-03。追跡済みリポジトリのREADME、販売資料、アプリ設定には、確定した事業用問い合わせ先が見つからなかった。GitHubプロフィール、個人メール、過去会話から推測・転用していない。

Androidのビルド時 `INTERCOM_SUPPORT_EMAIL` を設定すると「お問い合わせ」が表示され、メールアプリを開く。未設定なら表示しない。形式検証あり。今回値は設定していない。新規メール作成、外部公開、メール送信も行っていない。

販売前に必要：運営者名、ユーザーが指定/確認した事業用メール、対応時間、返答目安、障害時の案内、プライバシーポリシーURL、データ削除窓口。メールを実際に受信できるかユーザー側で試験する。ストア・プライバシーポリシー・アプリで同じ値に統一する。電話・住所等の表示要件は販売形態とConsoleで確認する。

資料は未公開の草案のまま。未設定の画面が販売準備完了を意味するものではない。
